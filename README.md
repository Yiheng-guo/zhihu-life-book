# 人生之书 · 知乎黑客松

以知乎经历与建议为入口的互动人生叙事：从“如果当年……”的回望开始，选择一条路径，再把问题带回今天。

## 当前版本

`1.3`。版本号只使用两段：`1.0`、`1.1`、`2.0`；历史基线保留为 `v1.0.0`。

在线体验：<https://renshuzhi-shu.guo131378.chatgpt.site>

## 本版可体验

1.3 让选择改变后续处境：先查规则和先做尝试，会进入不同的探索页；探索行动继续通向学习、作品、岗位了解或可持续规划等处境。上页选中的知乎内容增加一个可选行动，采纳后也会改变下一步处境。

每页保留 3 条知乎经历或建议。卡片先呈现一句摘要，标题与详细摘要按需展开；原文链接独立保留。毕业先呈现与路径相关的 3 种可能，其余 5 种可以展开，不把任何前置选择当作结果保证。结尾回顾每次取舍，书签中的行动与当前毕业处境对应。

公网仍是预先整理内容和确定性分支，无运行时 Agent；响应不需要等待模型。本地 Node API 与静态版共享状态机。下一轮的实时知乎内容助手方案见架构文档，尚未接入网站。

## 目录

- `frontend/`：页面、样式、内容与共享状态机
- `backend/`：同源 Node API（本地开发与后续服务部署）
- `scripts/`：构建脚本
- `tests/`：状态机与 API 测试
- `docs/`：产品、比赛、API、团队流程与验收文档

## 本地运行

```bash
npm test
npm run build
npm run dev
```

打开 `http://127.0.0.1:4173`。本地 Node 服务使用 API 模式；公网静态站点使用预先整理内容。

## 安全边界

知乎 Access Secret、OAuth App Key、模型密钥只放服务端环境或安全凭证系统，不提交到仓库、前端、URL、日志或截图。真实素材保留原文链接与证据边界，不把单个作者经历写成统计结论。

技术现状、验证范围与下一轮 Agent 路线见 [架构说明](docs/ARCHITECTURE.md)。
