# 人生之书 · 知乎黑客松

以知乎经历与建议为入口的互动人生叙事：从“如果当年……”的回望开始，选择一条路径，再把问题带回今天。

## 当前版本

`1.2`。版本号只使用两段：`1.0`、`1.1`、`2.0`；历史基线保留为 `v1.0.0`。

在线体验：<https://renshuzhi-shu.guo131378.chatgpt.site>

## 本版可体验

1.2 增加暖金动态封面、人生路径渐显、鼠标光线互动和翻开转场。主体沿用 1.1 四节点体验，后续页面设计由前端两位成员深化。封面模块与故事逻辑分离，系统开启“减少动态效果”时自动关闭动画。

大学篇由“入学—探索—大三准备—毕业”四个节点组成。每一页有多条知乎经历或建议，选择卡片后才可继续；打开知乎原文是独立溯源入口。结尾会回顾你的选择，并生成一个只下载到本机的“今天的书签”。

当前公网版本使用预先整理的内容，未在运行时接入生成式 Agent。`backend/server.mjs` 提供同源 Node API 与会话状态机，静态站点和 API 共享 `frontend/story.mjs`，方便后续接入知乎搜索/直答，并保留静态体验模式。

## 目录

- `frontend/`：页面、样式、内容与共享状态机
- `backend/`：同源 Node API（本地开发与后续服务部署）
- `scripts/`：构建脚本
- `tests/`：状态机与 API 测试
- `docs/`：产品、比赛、API、团队流程与验收文档

## 本地运行

```bash
npm test
npm run build
npm run dev
```

打开 `http://127.0.0.1:4173`。本地 Node 服务使用 API 模式；公网静态站点使用预先整理内容。

## 安全边界

知乎 Access Secret、OAuth App Key、模型密钥只放服务端环境或安全凭证系统，不提交到仓库、前端、URL、日志或截图。真实素材保留原文链接与证据边界，不把单个作者经历写成统计结论。

技术现状、验证范围与下一轮 Agent 路线见 [架构说明](docs/ARCHITECTURE.md)。
