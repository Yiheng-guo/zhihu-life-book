# 人生之书 · 大学篇产品流程（1.3）

这份文档先固定“用户怎么走、每一步看什么、知乎怎样进入”，视觉动效和最终页面实现交给前端成员继续深化。

## 一句话流程

看到一句沉重的遗憾 → 做一个当下选择 → 选一条知乎经历或建议 → 带着它留下的问题进入下一阶段 → 在毕业处分岔 → 回望整条路径并带走一个今天能做的行动。

## 当前的分叉规则

- 入学选“先问”：探索页为准备申请 / 先旁听；选“先试”：探索页为做小项目 / 缩小尝试。
- 探索后的大三处境分为学习、作品、岗位了解、可持续规划，各有两项相应行动。
- 探索与大三还各有一项受上页知乎内容启发的小行动；更换来源会改变该行动，选择它可改变后续处境。
- 毕业先显示与路径有关的三种可能，另外五种可展开。它们都是阅读情境，不是系统的预测。
- 来源只提供参照，剧情是产品编排，不能把多个作者拼成一个人的完整人生。

## 用户旅程

| 画面 | 用户看到 | 用户动作 | 系统留下什么 |
|---|---|---|---|
| 封面 | “那一年，真的决定了一生？”两句引导 | 点击“翻开大学篇” | 建立大学篇阅读状态 |
| 01 入学 | 录取结果已经确定；两个选择：先问别人，或先做一件小事 | 选择 A/B | 记录第一次选择，进入对应回声 |
| 来源页 | 与本阶段相关的 3 条知乎经历/建议，显示类型、作者和短摘要 | 选中 1 条；原文可单独打开 | 记录 source_id；出现“留给你的问题” |
| 02 探索 | 根据入学行动，进入查规则后的探索或第一次尝试后的探索 | 选一个相应行动，或采纳上页来源启发的行动 | 记录行动与取舍，决定大三的处境 |
| 来源页 | 探索阶段的内容组合，优先展示经验自述 | 选中 1 条后继续 | 问题随来源改变，不是固定文案 |
| 03 大三准备 | 根据前面行动，进入学习、作品、岗位了解或可持续规划处境 | 选一个相应行动，或采纳上页来源启发的行动 | 记录选择，改变毕业页的上下文与优先展示顺序 |
| 来源页 | 岗位日常、考研失利、规划建议等内容 | 选中 1 条后继续 | 形成毕业前最后一个承接问题 |
| 04 毕业 | 同届没有同一个终点 | 选择读研、考公、工作、Gap Year、仍迷茫、暂未就业、延后毕业等情境 | 只生成产品编排的情境，不预测用户结果 |
| 回望 | 一条时间线、最终情境和“今天的书签” | 修改今天的一步，下载到本机 | 路径摘要、来源链接、用户自己的行动 |

## 重要交互规则

1. 剧情选择和知乎来源选择是两层动作，不能合并成一个点击。
2. 来源卡片有明确“已选中”状态；“打开知乎原文”是独立链接，不改变当前阅读状态。
3. 未选来源时，“继续下一页”保持禁用，并提示“请先选中一条内容”。
4. 换来源会即时替换承接问题；继续后下一节点会显示上一页的问题和来源标题。
5. 每个节点只能前进一次；毕业结局进入回望页，不能再回到毕业选择造成循环。
6. 回望页明确区分“暂未找到工作”和“延后毕业”；两者都不被写成失败判定。
7. 页面只在本机记录当前路径；公网静态版刷新即重新开始，不上传用户输入。

## 四段故事的情绪递进

- **入学：** 过去的分数已定，但大学的使用方式还没有定。
- **探索：** 不急着证明适合一生，先用一次低成本行动获得反馈。
- **大三准备：** 把目标、资源和生活成本放在同一张桌上。
- **毕业：** 结果发散，任何一条都不是对人的排序；关键是把沉重归因换成下一步问题。

## 知乎结合方式

每个节点先由产品编辑确定需要回答的问题，再从知乎搜索结果中挑选与阶段匹配的内容。页面保留标题、作者、类型、短摘要和原文链接；作者自述不写成普遍统计，建议不冒充作者原话。当前版本使用预先整理的 7 条来源；后续内容助手应返回同样字段，并由后端做链接、来源类型、缓存和额度失败校验。

## 路演推荐演示

3 分钟只演示两次关键决策，不把全部四节点当成操作速度比赛：开场 → 入学选择 → 选中一条来源 → 展示承接问题 → 探索选择 → 快速展示毕业分岔与回望。评委应在 20 秒内明白“选来源会改变下一页的问题”，在 60 秒内看到知乎原文溯源，在 150 秒内看到发散结局和今天的行动。

## Agent 介入点（下一轮）

Agent 不从封面开始，也不接管整个故事。探索节点里，用户先选了自己的行动，再选一条知乎经历，页面出现一个可选按钮“问问这段经历”。点击后返回短结构化卡片：可能得到、可能付出、可以先试的一步、下一问和 2–3 个知乎引用。它只丰富当前节点，不跳转、不改结局。搜索失败时回退到团队预整理内容并明确标注；每次体验最多两次调用，默认只演示一次。
