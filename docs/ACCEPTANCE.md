# 1.3 验收清单

## 产品体验

- [x] 首屏说明“人生之书”与遗憾入口。
- [x] 四个连续节点：入学、探索、大三准备、毕业。
- [x] 每个节点提供多条知乎经历或建议；卡片可选中且有明确状态。
- [x] “打开知乎原文”与“继续下一页”分离。
- [x] 选中的来源会带出承接问题，结尾回顾沿途选择。
- [x] 毕业结局区分读研、考公、工作、Gap Year、迷茫、暂未就业、延后毕业等情境。
- [x] 结尾可编辑并下载只保存在设备上的“今天的书签”。

## 技术与安全

- [x] 前端不包含 Access Secret、App Key、OAuth Token 或模型密钥。
- [x] 同源 Node API 与静态体验共享故事状态机。
- [x] API 有内存会话、来源/选择校验、过期更新防护、错误码和请求体上限。
- [x] `GET /healthz` 可验证服务存活。
- [x] `npm test` 覆盖状态机、来源约束、八种结局、会话隔离和 API。
- [x] 公网版标注预先整理内容，未把静态内容称为运行时 AI。

## 比赛交付

- [x] 发布后核对公网部署状态与版本内容。
- [x] 本地浏览器已完整验证静态与 API 两种体验模式。
- [x] 代码仓库有 README、启动说明、接口约定和版本记录。
- [x] 规则文档记录官方评分权重与 3 分钟 Demo + 2 分钟问答。

## 下一轮 P0
