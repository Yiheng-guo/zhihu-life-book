# 现场 Demo 脚本（约 3 分钟）

## 0:00–0:25｜开场钩子

> “未能珍惜年少考入好大学，以致此生碌碌无为。”

这句话把今天的失意归因到过去的一个结果。我们从知乎的经历与建议出发，把它改写成一个可以继续追问的问题。

## 0:25–1:05｜入学与第一次选择

点击“翻开大学篇”，选择“先去了解别人怎么走过这段路”。页面进入第二节前，展示三条来源卡片；点选一条卡片，说明“已选中”，再演示旁边独立的“知乎原文”链接。

讲述：

> 页面不会替用户选择，也不会让来源链接劫持当前流程。你选中的内容会留下一个问题，带着它进入下一页。

## 1:05–2:05｜探索与大三准备

点击“带着这段内容，继续”，演示“探索”节点，再用第二次选择进入“大三准备”。展示上页书签问题如何出现在下一页。

讲述：

> 情境是产品编排，知乎卡片保留来源类型与原文入口；个人经历是作者自述，建议就是建议，我们不把它们改写成统一的成功模板。

## 2:05–2:45｜毕业与发散结局

进入“毕业”，选择一条结局。展示读研、考公、工作、Gap Year、仍然迷茫、暂未就业和延后毕业的不同标签，再合上大学篇。

> 过去的结果已经确定，但它不必成为解释一生的唯一答案。每个人都可以把沉重的判断，换成今天愿意尝试的一步。

## 2:45–3:00｜收束

展示回顾时间线和“今天的书签”，说明书签只下载到设备。后续版本再接入一个有出处约束的知乎内容助手，让用户带着自己的问题获得实时帮助；当前 1.1 不把预先整理内容称为运行时 Agent。
